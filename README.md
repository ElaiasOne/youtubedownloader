# YouTube Video Downloader

Una aplicación de escritorio moderna desarrollada con **Electron**, **yt-dlp** y **FFmpeg** para descargar videos y audio de YouTube, recortar fragmentos multimedia y convertir formatos de audio y video.

## Características

- 🎥 **Descarga de Videos y Audio**: Soporta resoluciones (1080p, 720p, 480p, Máxima) y conversión a MP3 de alta calidad (320kbps).
- 🖼️ **Vista Previa de Video**: Detección automática del título y miniatura al pegar un enlace de YouTube.
- 📊 **Barra de Progreso**: Indicador porcentual de avance en tiempo real.
- ✂️ **Herramientas de Edición**: Recorta fragmentos de cualquier archivo multimedia local.
- 🔄 **Conversión de Formatos**: Convierte entre MP3, MP4, WAV, MKV, AVI, AAC y FLAC.
- 📂 **Acceso Rápido**: Abre la carpeta de descargas con un solo clic.
- 🛑 **Control de Procesos**: Detén cualquier descarga o conversión en curso.

## Requisitos

- Windows 10/11
- [Node.js](https://nodejs.org/) (v16 o superior)
- `yt-dlp.exe` y `ffmpeg.exe` en la raíz del proyecto.

## Instalación y Ejecución

```bash
# Clonar repositorio
git clone https://github.com/ElaiasOne/youtubedownloader.git

# Instalar dependencias
npm install

# Iniciar la aplicación
npm start
```
